# Public product site source

The live product introduction and interactive WebGL preview are at https://ue-asset-atlas.rogan2534.chatgpt.site.

This folder contains the buildless static source. It has no account, backend, analytics, third-party script or generated artwork dependency. Open `dist/index.html` locally or serve `dist/` with any static web server. The hosted Sites deployment configuration and credentials are intentionally not part of this public repository.
